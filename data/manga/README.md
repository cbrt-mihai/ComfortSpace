# Manga library (local only)

Place your CBZ files here. This folder structure is tracked in git; the archives themselves are not.

```
data/manga/
└── your-series-slug/
    ├── series.json    # optional metadata (safe to commit)
    ├── v01.cbz
    └── v02.cbz
```

Copy your own `.cbz` files into a series folder, then run the app and click **Rescan library**.

See the main [README](../../README.md#adding-manga) for naming conventions and `series.json` format.
